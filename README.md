# One-Line Cat Joke

Entry for [The One-Line Cat Joke That Lands](https://make.fun/c/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262) on make.fun — a single joke about cats, one line under 200 characters.

## The joke

> My cat knocked my coffee off the table, looked me dead in the eye, and I apologised to her.

## How to run

```sh
python3 main.py
```

This writes the joke, exactly as above and nothing else, to `/output/entry.txt`.
